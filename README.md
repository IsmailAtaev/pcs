# Promocode Systems (pcs)

Реализация REST API для системы промокодов.

## Стек технологий
* Node.js
* TypeScript
* Fastify
* PostgreSQL
* Kysely (ORM)
* Zod (валидация)
* @ts-rest/fastify (типизированный роутинг)

## Запуск

### С помощью Docker (рекомендуется)
1. Убедитесь, что у вас установлен Docker и Docker Compose.
2. В корне проекта выполните команду: `docker-compose up -d --build`
3. Сервер будет доступен по адресу: `http://localhost:4000`, а миграции накатываются автоматически при старте контейнера.
4. Документация (Swagger UI) доступна по адресу: `http://localhost:4000/docs`.

### Локально без Docker
1. Создайте базу данных в PostgreSQL.
2. Скопируйте `.env.example` в `.env` (или настройте `.nev` файл) и укажите корректный `DATABASE_URL`.
3. Установите зависимости: `npm install`.
4. Запустите миграции: `npx kysely migrate:latest` (или `npm run reset`).
5. Запустите сервер: `npm run dev`.

## Документация по API

Базовый путь: `/api/promocodes`

### 1. Получение списка промокодов
**Метод:** `GET /api/promocodes`  
**Описание:** Возвращает список всех промокодов с пагинацией. Поддерживает фильтрацию по ID или частичному совпадению кода.  
**Query-параметры:**
* `limit` (number, опционально) — ограничение количества записей (по умолчанию 10)
* `page` (number, опционально) — номер страницы (по умолчанию 1)
* `code` (string, опционально) — поиск по коду
* `id` (string, опционально) — поиск по точному ID

**Успешный ответ (200):**
```json
{
  "count": 1,
  "data": [
    {
      "id": "uuid",
      "code": "SUMMER2026",
      "discount": 15.5,
      "maxUses": 100,
      "usedCount": 5,
      "expiresAt": "2026-12-31T23:59:59Z",
      "createdAt": "2026-05-02T10:00:00Z"
    }
  ]
}
```

### 2. Создание промокода
**Метод:** `POST /api/promocodes`  
**Описание:** Создает новый промокод.  
**Тело запроса:**
```json
{
  "code": "WINTER2026",
  "discount": 20,
  "maxUses": 50,
  "expiresAt": "2026-12-31T23:59:59.000Z"
}
```

**Успешный ответ (201):**
```json
{
  "id": "uuid",
  "code": "WINTER2026",
  "discount": 20,
  "maxUses": 50,
  "usedCount": 0,
  "expiresAt": "2026-12-31T23:59:59Z",
  "createdAt": "2026-05-02T10:00:00Z"
}
```

### 3. Просмотр одного промокода
**Метод:** `GET /api/promocodes/:id`  
**Описание:** Возвращает информацию о конкретном промокоде по его ID.  
**Успешный ответ (200):** Возвращает объект промокода.  
**Ошибка (404):** Если промокод не найден.

### 4. Получение списка активаций промокода
**Метод:** `GET /api/promocodes/:id/activations`  
**Описание:** Возвращает список всех активаций (email пользователей, которые применили этот промокод) для конкретного промокода.  
**Успешный ответ (200):**
```json
{
  "count": 1,
  "data": [
    {
      "id": "uuid",
      "promocodeId": "uuid-promocoda",
      "email": "user@example.com",
      "createdAt": "2026-05-02T10:05:00Z"
    }
  ]
}
```

### 5. Активация промокода
**Метод:** `POST /api/promocodes/:id/activate`  
**Описание:** Активирует конкретный промокод для указанного email. При активации счетчик `usedCount` у промокода увеличивается. Если срок действия промокода истек, исчерпан лимит или этот email уже активировал данный промокод, возвращается ошибка. Логика защищена транзакцией с блокировкой записи (FOR UPDATE), что гарантирует защиту от race condition при конкурентных запросах.  
**Тело запроса:**
```json
{
  "email": "user@example.com"
}
```

**Успешный ответ (200):**
```json
{
  "id": "uuid",
  "promocodeId": "uuid-promocoda",
  "email": "user@example.com",
  "createdAt": "2026-05-02T10:05:00Z"
}
```
**Возможные ошибки (400 Bad Request):**
* `Promocode is expired` — срок действия промокода истек.
* `Promocode usage limit reached` — лимит использования достигнут (`usedCount >= maxUses`).
* `This email has already activated this promocode` — промокод уже активирован на этот email.
